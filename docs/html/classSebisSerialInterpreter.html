Detailed Description

Reads lines from a Stream and calls the function of every registered code in them, in input order.

A line ends with LF, CR or CR LF (counts once). A code is case-sensitive letters followed directly by -?[0-9.,]+, e.g. X10, Y-2.5, Z1,5; anything else separates codes. A comma counts as decimal point and the longest valid number at the start is used: X1.2.3 gives 1.2, X. gives 0. A code without a number is ignored. No leading +, no exponents (X1e3 is X1 and e3), G-code comments are not skipped.
